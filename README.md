## 🚀 Features
- **Interactive CLI:** Users navigate via commands like `bio`, `projects`, and `skills`.
- **Matrix Rain Background:** High-performance HTML5 Canvas animation.
- **Boot Sequence:** Simulated system initialization for immersion.
- **Functional Commands:** - `cv`: Triggers a secure PDF download with a simulated loading bar.
  - `matrix`: Secret "Overload" animation command.
  - `hire`: Direct deep-link to email client.
  - `contact`: Clickable links for WhatsApp, Phone, and GitHub.

## 🛠️ Tech Stack
- **HTML5** (Structure)
- **CSS3** (Retro CRT effects, Glitch animations, Scanlines)
- **JavaScript (ES6)** (Terminal logic, Canvas API, Event handling)

## ⌨️ How to Use
Type any of the following commands in the terminal input:
- `help` - List all available commands.
- `bio` - Read the developer profile.
- `skills` - View technical proficiency bars.
- `projects` - See recent builds and links.
- `cv` - Download the official resume.
